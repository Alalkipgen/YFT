# YFT Phase Prompts

These prompts let a new coding chat continue the YFT Android project without relying on earlier chat history.

## How to use

1. Paste `00_MASTER_PROMPT.md` into the new chat.
2. Set `CURRENT_PHASE` to the required phase.
3. Paste the matching phase prompt.
4. Keep `ALLOW_PUSH` and `ALLOW_RELEASE` false unless you intentionally authorize them.

After Phase 0, use the shorter Burmese `GENERIC_PROMPT_MM.md` for normal work. The numbered prompts remain reference material only.
