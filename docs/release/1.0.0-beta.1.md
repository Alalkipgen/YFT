# Video Downloader 1.0.0-beta.1

**Beta for sideload testing.** Video Downloader (YFT) is an ad-free Android app that detects,
previews and downloads authorized, non-DRM media from direct links, HTML5 players, HLS and DASH
streams. It never bypasses DRM, payment, login or other access controls.

## Requirements

- Android 7.0 (API 24) or newer; built for Android 15 (API 35).
- A network connection. The in-app browser loads HTTPS pages only.

## Install

1. Download `video-downloader-1.0.0-beta.1.apk` and `SHA256SUMS` from the release assets.
2. Check the file against the SHA-256 under "Verify the download" below:
   - Linux: `sha256sum -c SHA256SUMS`
   - macOS: `shasum -a 256 -c SHA256SUMS`
   - Windows PowerShell: `Get-FileHash .\video-downloader-1.0.0-beta.1.apk -Algorithm SHA256`
3. Open the APK on the phone. When Android asks, allow your browser or file manager to install
   unknown apps (Settings › Apps › Special app access › Install unknown apps).
4. Optional: `apksigner verify --print-certs video-downloader-1.0.0-beta.1.apk` should print the
   signing certificate SHA-256 shown below.
5. On Android 13 or newer, allow notifications so download progress and controls are visible.

Later releases signed with the same key install over this one and keep settings and downloads.
If Android refuses an update, the installed copy was signed with a different key; uninstalling
it first deletes its settings and app-private downloads.

## What it does

- Paste a link on Home or browse a site in the hardened in-app browser.
- Detects direct files (MP4, WebM, audio), HLS and DASH streams, including the real source behind
  `blob:` players, and lists them under Detected Media.
- Preview shows the real video and audio variants with resolution, frame rate, codec, bitrate,
  duration and exact, estimated or unknown size.
- Downloads with pause, resume, retry, a foreground service and recovery after a restart.
  Finished files go to `Download/YFT` on Android 10 and newer, and to app storage on older
  versions; the Library plays, opens, shares and deletes them.
- TikTok, Facebook and Vimeo adapters, and single YouTube videos as progressive MP4 (usually up
  to 360p) plus M4A audio. Other sites use generic detection.
- Settings for quality, download location, Wi-Fi only, mobile-data confirmation, concurrent
  downloads, theme and clearing browsing data or download history.

## Privacy

No ads, analytics, accounts or cloud backup. HTTPS only. Detected links stay in memory, logs
never contain cookies, tokens or signed links, and the clipboard is read only when Paste is
tapped. The About screen lists every third-party license.

## Known issues

- YouTube is limited to progressive MP4 (usually up to 360p) and M4A audio. Some videos fail
  with HTTP 403 because PO tokens are not supported, some networks get bot checks, and the
  player-script solver needs regular maintenance.
- Separate video and audio tracks are combined only for AVC/AAC in MP4/fMP4. DASH
  `SegmentBase`/SIDX and live streams are not supported.
- Saving to an arbitrary folder through the system picker is not available yet.
- An unfinished download whose link expired while the app was closed needs a fresh link from
  the page.
- The free-space check covers only exact sizes; estimated or unknown sizes stop cleanly if
  storage fills up.
- TikTok, Facebook and Vimeo support is verified against saved page fixtures; site changes can
  break it.

## Testing status

This beta passed the automated JVM, Robolectric and fixture test suite, Android lint, the
minified release build and APK signature verification. It has **not** yet been tested on a
phone or emulator by the maintainers: WebView rendering, YouTube on a real network, playback,
muxing, the foreground service, MediaStore publication, Library sharing, Wi-Fi switching,
notification permission and in-place upgrades are still device checks. Please report problems
through GitHub issues with the Android version, device model and the site's domain (never a
signed link, cookie or account detail).
