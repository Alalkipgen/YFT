# Video Downloader 1.0.0-beta.2

**Second beta for sideload testing, with the redesigned interface.** Every screen now follows the
YFT design: Mint and Deep Teal on a light surface or the Night theme, a new app icon, and Home,
Browser, Downloads, Library and Settings rebuilt around it. Features and download behaviour are
the same as in 1.0.0-beta.1. Video Downloader (YFT) is an ad-free Android app that detects,
previews and downloads authorized, non-DRM media from direct links, HTML5 players, HLS and DASH
streams. It never bypasses DRM, payment, login or other access controls.

## Requirements

- Android 7.0 (API 24) or newer; built for Android 15 (API 35).
- A network connection. The in-app browser loads HTTPS pages only.

## Install

1. Download `video-downloader-1.0.0-beta.2.apk` and `SHA256SUMS` from the release assets.
2. Check the file against the SHA-256 under "Verify the download" below:
   - Linux: `sha256sum -c SHA256SUMS`
   - macOS: `shasum -a 256 -c SHA256SUMS`
   - Windows PowerShell: `Get-FileHash .\video-downloader-1.0.0-beta.2.apk -Algorithm SHA256`
3. Open the APK on the phone. When Android asks, allow your browser or file manager to install
   unknown apps (Settings › Apps › Special app access › Install unknown apps).
4. Optional: `apksigner verify --print-certs video-downloader-1.0.0-beta.2.apk` should print the
   signing certificate SHA-256 shown below.
5. On Android 13 or newer, allow notifications so download progress and controls are visible.

1.0.0-beta.2 is signed with the same key as 1.0.0-beta.1 and has a higher version code, so it
installs over beta.1 and keeps settings and downloads. If Android refuses the update, the
installed copy was signed with a different key; uninstalling it first deletes its settings and
app-private downloads.

## What's new

- A new look everywhere: Mint and Deep Teal, the Plus Jakarta Sans typeface, rounded icons,
  bordered cards and pill buttons, a light theme and a Night theme (System, Light or Dark in
  Settings), and a new app icon and launch screen.
- A bottom bar with Home, Downloads (with a badge for active downloads), Library and Settings.
- Home: "Download from any link" with the link box — paste a link, or use a copied one, and YFT
  checks it for media without opening the browser — plus Your sites shortcuts and Recent files.
- Browser: an address pill with the lock, host and path, and a "Found on this page" sheet that
  rests above the toolbar. Protected (DRM) media are never listed; a note says how many were
  left out.
- Download as: a sheet over the page with a small preview player, Video and Audio, the qualities
  with their sizes, the Wi-Fi only switch and the size on the Download button.
- Downloads: All, Active, Queued, Done and Failed filters with counts, speed and time left,
  status chips that say why something waits or failed, Retry, a menu on every card and a
  storage line with the free space.
- Library: a two-column grid with each file's own picture, length and quality, search, sorting,
  a ⋯ menu (Play, Open with…, Share, Delete), a mini player for audio and full-screen video.
- Settings: Appearance, Downloads, Privacy and About groups, a stepper for downloads at the same
  time, and separate About and Licenses pages.
- Accessibility: every button has a TalkBack name and a touch area of at least 48dp, and text
  up to twice the normal size wraps instead of being cut off.

## What it does

- Paste a link on Home or browse a site in the hardened in-app browser.
- Detects direct files (MP4, WebM, audio), HLS and DASH streams, including the real source behind
  `blob:` players, and lists them under "Found on this page".
- Download as shows the real video and audio variants with resolution, frame rate, codec,
  bitrate, duration and exact, estimated or unknown size.
- Downloads with pause, resume, retry, a foreground service and recovery after a restart.
  Finished files go to `Download/YFT` on Android 10 and newer, and to app storage on older
  versions; the Library plays, opens, shares and deletes them.
- TikTok, Facebook and Vimeo adapters, and single YouTube videos as progressive MP4 (usually up
  to 360p) plus M4A audio. Other sites use generic detection.
- Settings for quality, download location, Wi-Fi only, mobile-data confirmation, downloads at
  the same time, theme and clearing browsing data or download history.

## Privacy

No ads, analytics, accounts or cloud backup. HTTPS only. Detected links stay in memory, logs
never contain cookies, tokens or signed links, and the clipboard is read only when Paste or Use
is tapped. Settings › Licenses lists every third-party license.

## Known issues

- YouTube is limited to progressive MP4 (usually up to 360p) and M4A audio. Some videos fail
  with HTTP 403 because PO tokens are not supported, some networks get bot checks, and the
  player-script solver needs regular maintenance.
- Separate video and audio tracks are combined only for AVC/AAC in MP4/fMP4. DASH
  `SegmentBase`/SIDX and live streams are not supported.
- Saving to an arbitrary folder through the system picker is not available yet.
- An unfinished download whose link expired while the app was closed needs a fresh link from
  the page.
- The free-space check covers only exact sizes; estimated or unknown sizes stop cleanly if
  storage fills up.
- TikTok, Facebook and Vimeo support is verified against saved page fixtures; site changes can
  break it.
- Playback in the Library and Downloads stops when YFT leaves the screen; there is no
  background playback.
- Downloads shows speed and time left only while the Downloads screen is open.

## Testing status

This beta passed the automated JVM, Robolectric and fixture test suite, Android lint, the
minified release build and APK signature verification. The new screens were also checked in
Robolectric: renders in the light and Night themes and at 130% and 200% text size were compared
with the design images, and an automated audit checked TalkBack names and touch areas on every
screen. It has **not** yet been tested on a phone or emulator by the maintainers: WebView
rendering, YouTube on a real network, playback, muxing, the foreground service, MediaStore
publication, Library sharing, Wi-Fi switching, notification permission, the new icon and launch
screen, and the update from beta.1 are still device checks. Please report problems through
GitHub issues with the Android version, device model and the site's domain (never a signed link,
cookie or account detail).
