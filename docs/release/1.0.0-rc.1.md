# Video Downloader 1.0.0-rc.1

**The release-key test build of 1.0.0 — for the owner's phone only, never published.** It is
1.0.0's code under the name `1.0.0-rc.1` and version code 999901, signed with the release key, for
the update test in P8 (`docs/IN_APP_UPDATE_PLAN.md` §5.5): installed on the owner's phone before
1.0.0 is published, it must find 1.0.0 once it is out, check it and install it. This draft release
is deleted after the test; friends get 1.0.0 (`docs/release/1.0.0.md`), never this build.

## Requirements

- Android 7.0 (API 24) or newer; built for Android 15 (API 35).
- A network connection. The in-app browser loads HTTPS pages only.

## Install

1. Download `video-downloader-1.0.0-rc.1.apk` and `SHA256SUMS` from this draft's assets.
2. Check the file against the SHA-256 under "Verify the download" below:
   - Linux: `sha256sum -c SHA256SUMS`
   - macOS: `shasum -a 256 -c SHA256SUMS`
   - Windows PowerShell: `Get-FileHash .\video-downloader-1.0.0-rc.1.apk -Algorithm SHA256`
3. Open the APK on the phone. When Android asks, allow your browser or file manager to install
   unknown apps (Settings › Apps › Special app access › Install unknown apps).
4. Optional: `apksigner verify --print-certs video-downloader-1.0.0-rc.1.apk` should print the
   signing certificate SHA-256 shown below.

1.0.0-rc.1 is signed with the same key as the betas and 1.0.0. Its version code 999901 (the
version code rule in `docs/RELEASE.md`) is above every beta's, so it installs over a beta and keeps
its settings and downloads, and below 1.0.0's 1000000, so 1.0.0 installs over it. Test builds
(`com.alal.yft.debug`, "YFT Preview", "YFT Trial") install separately and are not touched.

## The update test

1. Install this APK and open it: Settings → About shows `Version 1.0.0-rc.1 (999901)`, and
   Settings → About → Updates has **Check automatically** on (the release's default).
2. The owner publishes 1.0.0 (`docs/RELEASE.md` §5).
3. On the phone, YFT offers v1.0.0 with its release notes: **Check now** on the Updates screen
   finds it at once; without it, the daily check at an app open finds it and the screen opens by
   itself.
4. **Download APK to update** → "Verified: checksum and signature match" → Android's
   confirmation → 1.0.0 is installed: About shows `Version 1.0.0 (1000000)`; settings and
   downloads are kept.
5. Record the result in `docs/TEST_MATRIX.md` and `docs/PHONE_TEST_NOTES.md`, then delete this
   draft (and its tag, if one was pushed).

If the update fails, 1.0.0's own APK from its release still installs over the rc (a higher code,
the same key).
