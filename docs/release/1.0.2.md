# Video Downloader 1.0.2

**Easier sharing and saving, better DASH downloads, and fresh links.** Video Downloader (YFT) is
an ad-free Android app that detects, previews and downloads public, non-DRM media from links, HTML5
players, HLS and DASH streams. It never bypasses DRM, payment, private content or age checks, and
its site adapters never sign in.

## Requirements

- Android 7.0 (API 24) or newer; built for Android 15 (API 35).
- A network connection. The in-app browser loads HTTPS pages only.

## Install

**From 1.0.1:** Settings → About → Updates offers 1.0.2; YFT checks its checksum and signature,
then Android asks you to confirm. Settings and downloads stay.

By hand:

1. Download `video-downloader-1.0.2.apk` and `SHA256SUMS` from the release assets.
2. Check the file against the SHA-256 under "Verify the download" below:
   - Linux: `sha256sum -c SHA256SUMS`
   - macOS: `shasum -a 256 -c SHA256SUMS`
   - Windows PowerShell: `Get-FileHash .\video-downloader-1.0.2.apk -Algorithm SHA256`
3. Open the APK on the phone. When Android asks, allow your browser or file manager to install
   unknown apps (Settings › Apps › Special app access › Install unknown apps).
4. Optional: `apksigner verify --print-certs video-downloader-1.0.2.apk` should print the signing
   certificate SHA-256 shown below.
5. On Android 13 or newer, allow notifications so download progress and controls are visible.

1.0.2 uses version code 1000200 and is signed with the same key as 1.0.1, so it installs over
1.0.1 and keeps settings and downloads. If Android refuses the update, the installed copy may be
signed with a different key; uninstalling it first deletes its settings and app-private downloads.
Test builds install separately and are not replaced: `com.alal.yft.debug`, YFT Preview
(`com.alal.yft.preview`) and YFT Trial (`com.alal.yft.trial`).

## What's new

- **Share to YFT:** share a link from another app to open its Download sheet. Nothing downloads
  until you choose a row.
- **Choose a folder:** save new downloads to a folder on the phone or a memory card. If it becomes
  unavailable, YFT falls back to its default folder and says so.
- **Select several files:** remove or delete multiple finished downloads, or delete several files
  from the Library, with one confirmation.
- **More videos per post:** Instagram carousels and X posts with several videos list each video
  separately, with its own qualities and file.
- **Fresh links:** when a download link expires, YFT can look up the same video and quality again
  and resume. Retry also requests a fresh link where possible.
- **Weak-answer fill:** with Backup finder on, weak Facebook, Instagram and VK browser answers can
  get missing qualities or sound; the original rows stay first. Instagram's backup finder puts the
  best version of each height first.
- **DASH:** on-demand SegmentBase streams download and resume; segmented DASH video can be merged
  with its sound. Other fixes choose the requested quality and save long streams correctly.
- **Titles and audio:** confident Zawgyi titles are shown and saved in Unicode, with an option to
  use the original. MP3 conversion is faster.
- **Other fixes:** HLS previews with separate audio play with sound; recently ended YouTube lives
  download more reliably; quality labels, file names, folder display and download lists are clearer.

## Privacy

No ads, analytics, accounts or cloud backup. HTTPS only. YFT contacts the sites you open, the media
servers they point to and GitHub. The backup finder may read signed site data from GitHub; automatic
update checks ask GitHub about the newest release. Nothing about you or your downloads is sent.
Detected links stay in memory. Logs do not contain cookies, tokens or signed links. A site's cookies
and tokens stay in memory and go only to that site's own servers. The crash report stays on the
phone and is never sent automatically. About › Licenses lists third-party licenses.

## Known issues

- Sites change often; bot checks, sign-in walls and site changes can prevent a lookup. Some
  Instagram posts require a signed-in browser session; X protected and age-limited posts are not
  found.
- Some VK blank embed pages and clips moved to `vkuser.net` may not be found.
- An ended YouTube live's size estimate can be too high.
- DASH previews may fail when a manifest names media with an HTTP BaseURL, even if its download
  works over HTTPS. AV1 merging remains off.
- Update checks and in-app installs need GitHub. If an install fails, **Download in browser** opens
  the release APK.

## Testing status

Facebook, Instagram and X each passed three promotion runs on the earlier census build, with zero
wrong rows and no regression. Report problems through GitHub issues with the Android version,
device model and site's domain; never include a signed link, cookie or account detail.
