# Video Downloader 1.0.3

Video Downloader (YFT) is an ad-free Android app for detecting, previewing and downloading public,
non-DRM media. It does not bypass DRM, payment, private content or age checks.

## Requirements

- Android 7.0 (API 24) or newer.
- A network connection. The in-app browser loads HTTPS pages only.

## Install or update

From 1.0.2, check Settings → About → Updates. YFT verifies the checksum and signature before
Android asks you to confirm installation. The release is built with version code 1000300.

To install manually, download `video-downloader-1.0.3.apk` and `SHA256SUMS` from the release
assets. Verify with `sha256sum -c SHA256SUMS` on Linux or `shasum -a 256 -c SHA256SUMS` on
macOS, then open the APK on the phone and approve installation. Updates require the same signing
key; uninstalling an existing app removes its settings and app-private downloads. Preview and
census builds are separate apps.

## What's new

- **All items:** select the available video items in a post and queue them at the default quality.
- **VK:** blank embed pages can use VK's API to find available qualities; moved media hosts are
  recognized.
- **Fresh link renewal:** a renewed link must be proven to be the same file. Retry can recover a
  download after the app closes, including when its link has expired.
- **Size estimates:** finished HLS streams and recently ended YouTube lives can show a clearly
  marked rough estimate when there is enough evidence.
- **Faster HLS:** download pieces and certain playlist reads can start in parallel.
- **Media detection:** HLS stream pieces are kept out of the video list, and live streams are set
  aside when a page has another video. A page's own media qualities stay grouped when the page
  identifies them as one video.
- **Wikimedia:** page links, WebM quality labels and resume on servers with unquoted ETags are
  handled more reliably.

## Known limits

- Sites change, and bot checks, sign-in walls or site changes can prevent a lookup.
- Similar durations alone do not prove two streams are the same video, so some qualities may appear
  separately. AV1 merging remains off.
- If a fresh link cannot be proven to be the same file, YFT keeps the existing bytes and asks you
  to open the page again.
